**Goal:** Ship iOS 1.1 with event reminders, Home/Lock Screen widgets, App Intents/Siri/Spotlight, a My Day planner, a grounds map, and an off-season landing state — answering the Guideline 4.2 rejection — plus the matching App Store listing refresh.

**Architecture:** All new pure logic lands in a new `ios/ChqCalendarShared/` synchronized folder group compiled into both the app target and a new `ChqCalendarWidgets` extension target, with data shared through an App Group (`group.org.chqcal.app`). **Design decisions already made (user-approved 2026-08-07):**
- Full scope: all of #177–#183.
- Off-season landing = season countdown + announced next-season events + one-tap past-season archive.
- New top-level `TabView`: Events / My Day / Map.
- **No location permission this version** — no blue dot, no `NSLocationWhenInUseUsageDescription`, no App Privacy change.
- Walking times from a checked-in static venue coordinate table (no routing calls, no runtime geocoding).
