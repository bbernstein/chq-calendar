# Bus & Tram Tracker Link (#158) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Bus & Tram Tracker" link (https://busandtramtracker.chq.org) to the iOS More menu and the web header, per issue #158.

**Architecture:** Pure data additions. iOS renders `AboutInfo.quickLinks` via `ForEach` in the toolbar More menu, so appending one `Link` is the whole iOS change. The web header hardcodes the same links twice (desktop row + mobile dropdown), so both branches get a button. Tests pin both lists.

**Tech Stack:** Swift 6 / Swift Testing (`@Test`/`#expect`) for iOS; Preact + Vitest + Testing Library for web.
