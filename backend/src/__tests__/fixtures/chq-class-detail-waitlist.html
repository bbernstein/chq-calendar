Watercolors for Beginners

This is an introductory level watercolor class for those with little to no-experience or those looking to strengthen their watercolor skills. This course introduces the Art Elements & Principles of Design, watercolor paints and supplies, foundational techniques in watercolor, color basics. Guided studio sessions will focus on painting simple objects, landscapes, flowers, some watercolor do's, don'ts, and how to secrets. This class has a materials fee payable directly to the instructor. Materials fee: $15.
